Profile

I work as a Senior Microsoft 365 Engineer for a global enterprise. In February 2023 I was awarded Microsoft MVP in M365 Apps & Services for Microsoft Teams. In July 2024, I was awarded MVP in Azure PowerShell as well. My main focus areas are Microsoft Teams Telephony and PowerShell. I also have experience with Azure (Virtual Machines, Load Balancers, Traffic Manager, Azure Functions, Automation Accounts etc.) and also like to tinker with Power Automate Flows.

Community Controbutions

M365 Call Flow Visualizer

I am the creator and inventor of the M365 Call Flow Visualizer. The Microsoft 365 Call Flow Visualizer is a PowerShell tool which I developed for the Teams community. This tool can automatically render flowchart diagrams of your Teams call flows. This is great for documenting and troubleshooting calls flows.
